## 0. 结论摘要

| 口径 | 分数 | 结论 |
|---|:---:|---|
| 纯软件工程（算法/协议/安全/集成/测试/前端/文档/工程化） | **≈ 7.9 / 10** | 逻辑扎实，测试真绿，属于个人项目上游水平 |

## 3. 逐维度优缺点

### 3.1 需求与范围控制 —— 9.0

**优点**
- `README.md` 的能力边界表把"已实现 / 待验证 / 不支持"分列，`❌ 定高/定点`、`⏳ 航向锁定` 写得很清楚。
- `docs/WORKPLAN.md` 粒度控制得当（工作项级、不估工时），有验收标准和依赖关系。
- 明确放弃过度设计，符合"学习参考型"定位。

**缺点**
- 标题级目标"能姿态自稳、航向锁定、手动飞行、短时小范围悬停"中，**航向锁定实际只做到偏航角速度保持**（磁力计未融合），容易被误读为已具备。
- `docs/ARCHITECTURE.md` 与 `README.md` 对"已完成/待建"的描述不同步（见 3.8）。

### 3.2 飞控算法逻辑 —— 8.5

**优点**
- 算法层全部是**纯 C 头文件、零 Arduino 依赖**（`firmware/src/flight/*.h`），可直接在 PC 上单测，这是很好的架构决策。
- D 项对**测量值**求导并有 `has_prev` 首拍保护（`pid.h`），消除打杆尖峰。
- 条件抗积分饱和（饱和且同号才停止积分），逻辑正确（`pid.h`）。
- 保均值抗饱和混控 `mixer_desaturate()`（`mixer.h:44`）保留差动力矩。
- 12% 怠速保底（`mixer.h:91`、`mixer_apply_idle` `mixer.h:117`）。
- 5%→满油门连续映射 + 差动权限渐入（`controller.h:31`、`controller.h:373`），消除怠速阶跃。
- 分级倾角保护：>110° 单拍断桨、>60° 归零目标 + 45% 油门 + 45° 滞回 + 320 拍（0.8 s）超时（`safety.h:18–25`、`safety.h:140–157`）。
- `LOWBAT_LAND` 单向锁存，防电压回弹抽搐（`safety.h:164`）。
- F-02 的 NaN 处理已改为"只积分不修正"（`mahony.h:89`、`controller.h:307`），不再用假水平拉偏。
- 陀螺 200 拍静止校准 + 手抖峰峰值 0.15 rad/s 重采（`controller.h`）。

**缺点**
- **有刷推力模型线性化**：混控按占空比线性分配（`mixer.h:103–109`），而有刷电机推力约正比于占空比²。力矩增益随油门变化，大机动线性度差（玩具级可接受，但不是物理精确）。
- **12% 怠速可能低于部分 8520 的启动占空比**，四路起转不对称 `[推断]`。
- **磁力计未融合**：`qmc5883p` 驱动存在，但 `main.cpp` 未包含、未初始化，yaw 无法锁定。
- **增益是桌面整定值**，外环 `kp=4.5`、内环 `kp=0.25/ki=0.08/kd=0.004`（`controller.h:125–133`）未经单轴台架验证。
- 混控保均值针对的是"平均占空比"，不是"平均推力"，在非线性推力模型下并不严格保推力。

### 3.3 固件集成 / 实时时序 —— 7.0

**优点**
- 双核职责干净：Core1 400Hz 控制、Core0 BLE/遥测/状态灯（`main.cpp`）。
- `esp_timer` 2500 µs 硬件周期触发（`config.h:45`），并用 `esp_timer_get_time()` 实测 `dt` 后钳位到 `[0.5, 1.5]×CTRL_DT`（`controller.h:226–234`）。
- 跨核采用"最新值覆盖"而非排队，符合遥控语义。
- 心跳故障与 PWM 写入共用 `s_motor_mux`（`main.cpp:58`、`main.cpp:131–150`、`main.cpp:178–185`），防止两核交错写四路 PWM。
- `heartbeat.h` 用无符号差值处理 49.7 天回绕，并防跨核 1 ms 读写偏斜（`heartbeat.h`）。
- 上电先 `motor_out_stop_all()` 再初始化外设。
- 启动阶段 MPU 失联时锁死电机并保持心跳（`main.cpp:94–106`）。

**缺点**
- **I2C 超时 5 ms > 控制周期 2.5 ms**（`config.h:30` vs `config.h:45`）。一次 burst 读包含 `endTransmission(false)` + `requestFrom` 两次事务，最坏可阻塞约 10 ms，直接破坏 400Hz 节拍 `[推断，需实测]`。
- `esp_timer` 使用 `ESP_TIMER_TASK` 派发而非 ISR，存在任务调度抖动（通常几十 µs 级）`[推断]`。
- 控制任务没有挂 `esp_task_wdt`，靠心跳补偿。
- 心跳的 `notifications == 0` 条件（`main.cpp:136`）一旦成立就锁存停机，且恢复要求"新鲜主动上锁命令"；若 BLE 同时断开，只能断电重启。这是"保安全牺牲可用性"的取舍，需台架确认不会误触发。
- 400Hz 循环里同时做 I2C + ADC + Mahony + 双环 PID，单拍预算仅 2.5 ms，余量未实测。

### 3.4 通信协议 —— 9.0

**优点**
- 13B 下行 / 19B 上行，均小于 20B，无需 MTU 协商。
- 帧头 + 长度 + CRC-8（poly 0x07）+ 量程四重校验（`protocol.h:146–179`）。
- `static_assert` 锁死帧长（`protocol.h:105–106`）。
- 小端序、2 字节自然对齐。
- 前后端逐字节对齐，Node 测试直接跑生产 TS。
- 断连立即置 `armed=false` + `throttle=0` + `s_has_valid_rx=false`（`ble_server.cpp:46–56`）。
- `ble_comm_get_command()` 在锁内取时并防下溢（`ble_server.cpp:141–148`）。

**缺点**
- **BLE 无配对/无鉴权**：附近任何人连上 UUID 即可发控制帧甚至 KILL。安全上是真实缺口。
- `seq` 被保存（`s_last_rx_seq`）但未用于去重/乱序判断；BLE 可靠传输下影响小，但属未用字段。
- `PROTOCOL_FLAG_HALF_RATE` 在协议、固件、仿真都实现了，但前端 `main.ts:173` 硬编码 `halfRate: false`，UI 无入口，是"可达性为零"的功能。
- 遥测 `notify()` 无节流/无拥塞判断（20Hz 下风险低）。

### 3.5 安全设计 —— 8.5

**优点**
- 五态状态机：LOCKED / ARMED / LOWBAT_WARN / LOWBAT_LAND / FAILSAFE。
- 解锁四重联锁：未失联 + 平放 ≤60° + 电压 ≥3.5V + 油门 ≤5%（`safety.h:107–115`）。
- 失联 500 ms → FAILSAFE 锁存。
- 三级姿态保护（>60° 救机、>110° 断桨、地面怠速翻倒单拍断桨）。
- `LOWBAT_LAND` 单向锁存。
- NaN/Inf 三层防火墙：输入有效性、Mahony 只积分、`safety_apply_motor_gate`（`safety.h:182`）。
- 地面怠速静默：解锁但油门 ≤5% 时清 PID、四路均匀 12%。
- 前端：切后台/失焦/退页/手柄断连/BLE 断连 → 强制上锁 + 油门归零 + 3 帧 KILL（`flight_logic.ts:240`、`main.ts:457–540`）。

**缺点**
- **无高度反馈**：45%/25% 油门上限只是"估≈悬停"的开环假设（`safety.h:22`、`safety.h` LAND 分支），实际可能掉高或上升。
- **电池 LPF 挡不住持续压降**：`CTRL_VBAT_LPF_ALPHA=0.02`（`controller.h:29`）在 400Hz 下 τ≈125 ms，只挡单拍毛刺；1S 大油门持续 sag 可能被误判为 3.3V 严重低压并单向锁存 `[推断]`。
- **地面怠速分支绕过电机总闸门**：`controller.h:328–331` 在 `safety_apply_motor_gate` 之前 `return`，12% 怠速不受门限约束（影响小，但是旁路）。
- **无物理解锁开关**：GPIO10 预留但固件未读取，只有软件解锁。
- **FAILSAFE 判定依赖 `cmd_age_ms`**，而 BLE 断连与超时的交互需要在实机验证。

### 3.6 地面站 / 前端 —— 8.0

**优点**
- Mode-2 → FRD 转换正确：前推 = 负俯仰前飞（`flight_logic.ts:65`）。
- 相对位移摇杆：落指即原点，触摸不跳变（`flight_logic.ts:115`、`joystick.ts`）。
- 死区显式归零（`applyAxisDeadzone`）。
- 增量油门 + 直映 Soft-Takeover 防暴冲（`flight_logic.ts:190`、`computeIncrementalThrottle`）。
- 生命周期安全：`visibilitychange` / `blur` / `pagehide` / `gamepad-disconnected` / BLE 断连。
- KILL 长按/边沿触发防误触；`<dialog>` 弹窗防卡死；Wake Lock 防锁屏。
- 离线仿真器覆盖 E-02 分级倾角、`LOWBAT_LAND` 锁存、F-06 权限渐入（`flight_logic.ts:342`）。
- 开发服务器有路径穿越测试（`verify_server.mjs`）。

**缺点**
- **Web Bluetooth 限制**：必须 HTTPS 或 localhost，且基本只有 Android Chrome/Edge；iPhone 只能 Capacitor 原生打包。
- **仿真器不是"1:1"**：只对齐常量与状态机，姿态动力学是简化模型，不含 AHRS/PID。
- **死代码**：`halfRate` 与 Trim（`rollTrimDeg`/`pitchTrimDeg`）逻辑写了也测了，但 `main.ts:173–174` 硬编码为 0/false，UI 无入口。
- 无遥测日志导出/回放，复盘只能看屏幕。
- 实体手柄轴映射写死为标准布局，非标准控（如某些航模 USB 控）需改代码。

### 3.8 文档准确性 —— 6.5

**优点**
- `ARCHITECTURE` / `DESIGN_FLOW` / `WORKPLAN` / `BOM` / `ERRATA` 五件套结构完整。
- `ERRATA` 的"修好了三标准"（代码对 + 有断言 + 干净环境跑过）是很成熟的工程习惯。
- `AGENTS.md` 作为红线文档，绝大多数条款在代码里确实被遵守（我逐条核对过 D 项、抗饱和、串级带宽、怠速、NaN、Mahony 窗、低压锁存、Mode-2 映射）。
- `§8 错题反思` 有真实的工程价值。

**缺点（本维度扣分主因）**
1. **P0 文档级炸机点**：`docs/ARCHITECTURE.md:226–229` 的混控矩阵与代码相反：
   - 文档：`M1 = T - P + R + Y` / `M2 = T + P + R - Y` / `M3 = T + P - R + Y` / `M4 = T - P - R - Y`
   - 代码（`mixer.h:103–109`）：`M1 = T + P - R + Y` / `M2 = T - P - R - Y` / `M3 = T - P + R + Y` / `M4 = T + P + R - Y`
   - 按文档接线：`roll>0` 会让右侧电机加速 → 实际左滚；`pitch>0` 会让后侧加速 → 实际低头。**与 `AGENTS.md §1` 也矛盾。**
2. **过时描述**：
   - `ARCHITECTURE.md:63,192` 仍写 LPF 30–50Hz，实际 80/40Hz（`controller.h:26–27`）。
   - `ARCHITECTURE.md:245` 仍写"倾角 >60° 立即切电"，实际已分级（`safety.h`）。
   - `ARCHITECTURE.md:79+` 仍把 `main.cpp`/`config.h`/多个驱动标为"待建/待合拢"。
   - 单测数量在 README/ARCHITECTURE/WORKPLAN 中分别写 6/7，实际 8。
3. **ERRATA 台账失同步**：主表 `docs/ERRATA.md:66–73` 把 F-01~F-06 全标 `⬜`，但工作区代码六条全部已实现（`main.cpp:136,179`、`controller.h:307`、`ble_server.cpp:55,148`、`controller.h:131,373`），§9 也写了已完成。
4. **物理公式写反**：`ERRATA.md §8.1` 写 `a_frd.z = -a_flu.z`，代码 `controller.h:205–209` 是 `accel_frd.z = +accel_flu.z`。
   - 注意：**代码是对的**（它输出的是"重力朝下方向在机体系中的表示"，与 Mahony 的 `v=(0,0,1)` 约定自洽，测试也验证了）。错的是文档里的那句解释，后续有人照文档改会把姿态弄翻。

### 3.9 硬件 / 可制造性 —— 4.0

**优点**
- BOM 便宜（≈¥78），选型理由充分。
- 电源树正确：1S → MT3608 升 5V → LDO 3.3V；明确指出 AMS1117 压差不够。
- 关键工程经验写进文档：8520 堵转约 4A 不能用 SS14(1A)；20kHz 而非 50Hz；PSRAM 占 GPIO35–37；QMC5883P 地址 0x2C 不是 L。
- 8 版板框迭代有记录。
