# 全流程设计路径（详细细化）

> 本文件是 `ARCHITECTURE.md` §9 的详细展开。从"立项 → 硬件 → 软件 → 首飞 → 扩展"逐阶段拆解，
> 每阶段给出：**动作 / 产出物 / 里程碑（验收标准）**，可单步推进、随时停下来验证。
> 选型与 BOM 见 `ARCHITECTURE.md` §1 / `docs/BOM.md`；逐条待办见 `docs/WORKPLAN.md`。

---

## 总览

```
P0 范围/选型 ─▶ P1 硬件(一体板) ─▶ P2 软件环境
                                      │
                        P3 驱动 ─▶ P4 算法+单测 ─▶ P5 双核任务
                                      │
                            P6 调参 ─▶ P7 首飞 ─▶ P8 扩展 ─▶ P9 归档
```

路径总原则：
- **先桌面单测（P4）再上板（P5）**：算法先在 PC 上验证，避免"上板才调算法"。
- **先姿态（P1–P7）后扩展（P8）**：阶段1 只做姿态自稳 + 航向锁定。
- 每阶段都有可验证里程碑。

---

## P0 · 范围与选型锁定
- **动作**：确认本期目标（姿态自稳 + 航向锁定 + 手动飞行 + 短时小范围悬停，**允许漂移**）；
  锁定 ESP32-S3、8520 有刷、1S 电池、WiFi 控制；BOM 定稿。
- **产出**：`ARCHITECTURE.md` §1 + `docs/BOM.md` + 范围表。
- **里程碑**：BOM ≈¥78（板免费 ≈¥70），范围"做/不做"双方认可。

## P1 · 硬件设计（板即机架）
- **动作**：
  1. 板框外形（v8 已有）→ **电机位改配 8520（φ8.6 压入孔 + 出线槽）**；
  2. 原理图：电源（1S→MT3608 5V、3.3V、VBAT 分压）、ESP32-S3、IMU+磁力计、4×MOS+SS34、接口；
  3. PCB：布局（MPU 居中）、电源/地、信号、机械配合、DRC；
  4. 打样（1.6mm FR4、5 片）、采购、焊接、装配、上电检查。
- **产出**：v9 DXF、原理图/PCB、Gerber、实物板。
- **里程碑**：5V/3.3V 正常、VBAT 读数正确、无短路与异常温升（不装桨）。

## P2 · 软件环境搭建
- **动作**：
  1. PlatformIO + ESP32 平台；`platformio.ini`（ESP32-S3、Arduino/ESP-IDF、分区、PSRAM）；
  2. 外设初始化：LEDC(20kHz)、I²C、ADC、GPIO、WiFi；
  3. `firmware/` 目录骨架（drivers/flight/comm/test）；
  4. 桌面侧单测框架。
- **产出**：可编译空工程、测试框架、README。
- **里程碑**：`pio run` 通过、USB 烧录成功、状态灯闪。

## P3 · 驱动层
- **动作**：
  1. MPU6050：初始化、量程、读原始数据；
  2. QMC5883P：初始化、读取、校准；
  3. 电机 PWM：LEDC 4 路 20kHz/10bit，上电默认 0；
  4. VBAT：ADC 采样 + 换算 + 滤波；
  5. 状态灯；WiFi AP + WebSocket；指令/遥测协议。
- **产出**：各驱动模块。
- **里程碑**：无桨下能看数据、发油门看 PWM 随动、未解锁电机不转。

## P4 · 算法层 + 桌面单测
- **动作**：
  1. 二阶巴特沃斯 LPF（30–50Hz）；
  2. Mahony 四元数姿态解算；
  3. 标定（陀螺零偏、加计水平）；
  4. 串级 PID（外环 100Hz / 内环 400Hz）；
  5. Quad-X 混控 + 电机约定；
  6. 安全逻辑（失联/倾角/低压/解锁）；
  7. 桌面单测：LPF/Mahony/PID/混控/安全。
- **产出**：算法模块 + 测试报告。
- **里程碑**：PC 上单测全绿，再上板。

## P5 · 任务编排（双核）
- **动作**：
  1. Core1：控制任务 400Hz（读 IMU → LPF → Mahony → PID → 混控 → PWM）；
  2. Core0：通信 50Hz、安全 20Hz、状态灯 2Hz；
  3. 队列与静态缓冲；看门狗；复位后安全状态。
- **产出**：任务创建与队列连接。
- **里程碑**：板上姿态输出平稳、不发散。

## P6 · 调试与调参
- **动作**：
  1. 手机端控制界面 + 遥测曲线；
  2. **单轴测试架**：锁 roll，先内环后外环；
  3. 先 roll/pitch 后 yaw；磁力计校准；
  4. 调参记录归档。
- **产出**：可调稳的飞控 + 调参日志。
- **里程碑**：roll/pitch 跟手、松手回中、yaw 可锁。

## P7 · 首飞
- **动作**：
  1. **无桨上电**：姿态平稳、电机转向正确；
  2. **无桨演练**：解锁/上锁、failsafe、倾角保护；
  3. **系绳/手托**：低油门验证回正；
  4. 低空渐进试飞。
- **产出**：首飞记录/视频。
- **里程碑**：系绳自稳、低空可控悬停、不翻机。

## P8 · 扩展（按兴趣逐项加）
- **动作**：BMP280/VL53L1X 定高；光流定点；定距移动（位置环 + 任务层）；App 完善。
- **里程碑**：每项独立可验证、可回退。

## P9 · 归档与发布
- **动作**：归档 Gerber/BOM/原理图；一键编译说明；README + GIF；打 tag。
- **里程碑**：他人可照文档复刻。

## 范围边界（阶段1）

| 类别 | 阶段1 包含 | 阶段1 不包含（另行扩展） |
|------|-----------|--------------------------|
| 传感 | MPU6050 + QMC5883P | BMP280/VL53L1X 定高、光流 |
| 算法 | LPF + Mahony + 串级 PID + Quad-X | 位置环、高度环、自主导航 |
| 控制 | WiFi App 手动（10–20m） | 定距移动、自动航线 |
| 飞行 | 姿态自稳、航向锁定、短时小范围悬停（允许漂移） | 定点悬停、定高、抗风 |
| 安全 | 失联/倾角/低压/解锁/急停 | 自动返航、地理围栏 |

> 一句话：**阶段1 让飞机"不翻、听指挥、大致悬停"**，精确位置/高度留给 P8。
