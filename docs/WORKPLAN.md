# 轻量无人机飞控 —— 工作计划（WORKPLAN）

> **一句话总目标**：用「板即机架」一体板 + **ESP32-S3 + MPU6050 + QMC5883L + 8520 有刷**，
> 做出**能姿态自稳、航向锁定、手动飞行、短时小范围悬停**的四轴（允许漂移），必购成本 ≈**¥75–83**。

**文档分工**（不重复维护）：

| 文档 | 回答什么 |
|------|----------|
| `docs/ARCHITECTURE.md` | 系统怎么构成（架构/算法/引脚/选型理由） |
| `docs/DESIGN_FLOW.md` | 为什么这么做（设计路径与决策依据） |
| **`docs/WORKPLAN.md`（本文）** | **怎么推进、做到什么算完**（工作项/产出物/验收/依赖/分工） |
| `docs/BOM.md` | 买什么、多少钱 |

**粒度约定**：只到**「工作项 / 交付物」级**（例：原理图设计、PCB 设计、校验），
**不写操作步骤级细节**（无函数名、无命令行、无软件点击流程），**不估工时天数**。

## 10. 安全红线（硬性，不可跳过）

| # | 红线 | 说明 |
|---|------|------|
| S-1 | **非飞行测试一律拆桨** | 调参/看数据/验转向，默认无桨 |
| S-2 | **首次飞行必须系绳或单轴架** | 未经约束验证不上自由飞 |
| S-3 | **上电默认锁定** | 任何输入不能绕过解锁；解锁后先低油门 |
| S-4 | **failsafe 每次飞行前演练** | 关 App/断 WiFi 实测收油 |
| S-5 | **物理急停随时可用** | PH2.0 可瞬断，人手可及 |
| S-6 | **人与桨盘面保持距离** | 起桨、调参、试飞时人不在桨平面内 |
| S-7 | **1S 锂电安全** | 平衡充、不过充过放、不摔包；充电有人在场 |

> 违反任一红线即停止操作，回到上一已验证状态。

### 13.2 风险与对策

| # | 风险 | 影响 | 对策 |
|---|------|------|------|
| R-1 | **8520 与 v8 的 φ14.2 电机位不匹配** | 电机装不上/晃动 | **P1-2 改 φ8.6 压入孔**，先用实物校核 |
| R-2 | 1S 直接进 AMS1117 压差不足 | ESP32 复位/重启 | **MT3608 升 5V**；5V 端 470µF |
| R-3 | WiFi 峰值电流导致掉电 | 空中重启 | 大电容 + 独立 5V 升压 + 电池 ≥25C |
| R-4 | 空心杯振动大 | 姿态噪声、难调参 | LPF 30–50Hz + MPU 泡沫减震 |
| R-5 | 磁力计受电机磁场干扰 | yaw 乱跳 | 远离电源线、校准、必要时不参与融合 |
| R-6 | 空心杯寿命短 | 推力衰减/烧电机 | 备用电机、飞后摸温、降油门 |
| R-7 | 无位置反馈 | 悬停会漂 | 明确接受；需要定点时上光流（P8） |
| R-8 | WiFi 延迟/断链 | 操控迟滞/失控 | failsafe 500ms + 室内低空 + 靠近飞 |
| R-9 | 焊坏 ESP32/模块 | 报废 | 排母插装 + 备用板（T5） |
