# 轻量无人机飞控 —— 架构设计文档（ARCHITECTURE）

> 定位：**开源学习参考型**飞控。代码以"清晰、模块化、好读"为第一原则，
> 不求功能最全，但求每一行都看得懂，方便他人照着学。
>
> 本文档只定**架构、模块划分、数据流、算法选型**，不含具体实现代码。

## 1. 设计基线（已与用户确认）

| 项目 | 选型 | 备注 |
|------|------|------|
| 主控 | **ESP32-S3 SuperMini**（双核 240MHz，USB-C） | 内置 WiFi/BLE；Core0 通信、Core1 控制 |
| 运行时 | **FreeRTOS 双核** | 通信与控制物理隔离，抖动小 |
| 开发框架 | **Arduino / ESP-IDF（PlatformIO）** | Arduino 上手快，必要时可下沉到 ESP-IDF |
| 主传感器 | **MPU6050**（I²C） | 3 轴加速度 + 3 轴陀螺仪 |
| 磁力计 | **QMC5883L**（I²C 0x0D） | 航向锁定，抑制 yaw 漂移 |
| 执行机构 | **4× 8520 空心杯 + 4× AO3400 + SS34** | 1S 直驱，低边 MOS |
| 电机 PWM | **LEDC 20kHz / 10bit** | 有刷高频 PWM（非舵机 50Hz） |
| 电池 | **1S 3.7V 600mAh ≥25C** | 悬停约 4–5A，续航 4–6 min |
| 电源 | **1S → MT3608 升 5V → ESP32**；传感器用板载 3.3V；**VBAT 分压进 ADC** | 1S 直接进 AMS1117 压差不够 |
| 控制链路 | **ESP32 自建 WiFi 热点 + 手机 App（WebSocket）** | 10–20m 内够用，免额外接收机 |
| 机架 | **嘉立创异形 PCB（板即机架）** | 100mm 对角轴距 |
| 算法 | **二阶巴特沃斯 LPF + Mahony 四元数 + 串级 PID + Quad-X** | 与成熟开源方案对齐 |
| 控制频率 | **内环 400Hz / 外环 100Hz / WiFi 50Hz** | 见 §6 |
| 安全 | 失联 500ms 收油、倾角 >60° 停机、低电报警、解锁、物理急停 | 见 §5.6 |
| 构建/IDE | VSCode + PlatformIO | 固件与算法测试统一管理 |

**技术栈一句话**：ESP32-S3 + FreeRTOS 双核 + Arduino/ESP-IDF，用 PlatformIO 构建，
算法用"桌面侧单元测试"先验证 —— 定位**开源学习参考型**项目。

### 1.1 为什么从 STM32 无刷改为 ESP32 有刷

| 原因 | 说明 |
|------|------|
| 成本 | 无刷方案 ≈¥193；有刷方案 **≈¥66–74** |
| 复杂度 | 免电调校准、免 BLHeli、免信号地处理；MOS 直驱最直观 |
| 控制链路 | ESP32 自带 WiFi，**省掉蓝牙模块/遥控器**，手机即可 |
| 算力 | 双核 240MHz，跑 400Hz 控制 + WiFi 绰绰有余 |
| 代价 | 空心杯寿命短、效率低、抗风差；但本项目目标只是"能大致飞" |

### 1.2 参考项目（选型依据）

| 项目 | 参考点 |
|------|--------|
| Micro ESP32 Drone（同事方案，45 元） | ESP32 双核分工、WiFi 网页遥控、Mahony + LPF、倾角保护 |
| Crazyflie | 空心杯 + PCB 机架 + 小轴距的标杆 |
| Quicksilver / EmuFlight | 串级 PID + Quad-X 混控的通用结构 |

## 4. 数据流（核心结构体）

```c
typedef struct {              // 原始 IMU
    float accel[3];           // m/s^2
    float gyro[3];            // rad/s
    uint32_t t_ms;
} ImuRaw_t;

typedef struct {              // 姿态
    float roll, pitch, yaw;   // rad（欧拉角，输出用）
    float q[4];               // 四元数（内部）
    float rate[3];            // rad/s
} Attitude_t;

typedef struct {              // 摇杆指令（App→飞控）
    float throttle;           // 0~1
    float roll_sp;            // rad
    float pitch_sp;           // rad
    float yaw_rate_sp;        // rad/s
    bool  armed;
} Setpoint_t;

typedef struct {              // 混控输出
    float motor[4];           // 0~1
} MotorCmd_t;

typedef struct {              // 状态（飞控→App）
    Attitude_t att;
    float vbat;
    uint8_t state;            // LOCKED / ARMED / FAILSAFE / LOWBAT
    uint32_t loop_us;
} FlightStatus_t;
```

## 5. 算法选型（重点）

### 5.1 数字滤波：二阶巴特沃斯低通（LPF）

空心杯 4 万转以上，机械振动极强，**必须先滤波再进姿态解算**。

- 类型：二阶巴特沃斯（Butterworth），通带平坦、无相位失真尖峰；
- 截止频率：**30–50Hz**（先 40Hz，按实测调）；
- 作用对象：陀螺仪三轴（主要）、加速度计三轴（可选）；
- 实现：双二阶（biquad）差分方程，系数用固定采样率（400Hz）预先算好。

> 不滤波的典型现象：电机一转，roll/pitch 就开始高频抖，PID 无法收敛。

### 5.2 姿态解算：Mahony 互补滤波（四元数）

- 输入：陀螺角速度 + 加速度计重力向量（+ 磁力计航向，可选）；
- 输出：四元数 → 欧拉角 roll / pitch / yaw；
- 参数：`Kp`（加速度计信任度）、`Ki`（陀螺零偏补偿）；
- 相对欧拉角互补滤波的优势：**无万向锁**、大角度机动更稳。

> 磁力计参与时，yaw 不再靠积分漂移；不接磁力计时，yaw 仅陀螺积分，会缓慢漂。

### 5.3 控制器：串级 PID

```
角度设定 ─▶[外环 100Hz]─▶ 目标角速度 ─▶[内环 400Hz]─▶ 力矩 ─▶ 混控
              ▲                              ▲
          当前角度                       陀螺角速度
```

- 三轴各一套：roll / pitch / yaw；
- 内环必须**限幅**（防积分饱和）、外环输出限幅（限制最大角速度）；
- yaw 用**角速度环**（不接磁力计时不做角度环）。

### 5.4 混控：Quad-X

电机编号与转向（**必须与实物一致**）：

| 电机 | 位置 | 转向 |
|------|------|------|
| M1 | 右前 | CCW |
| M2 | 右后 | CW |
| M3 | 左后 | CCW |
| M4 | 左前 | CW |

```
M1 = T - P + R + Y
M2 = T + P + R - Y
M3 = T + P - R + Y
M4 = T - P - R - Y
```

> `T`=油门, `R`=roll, `P`=pitch, `Y`=yaw。**符号以实机验证为准**：若某个轴反向，整体取反该轴即可。

### 5.5 输出：LEDC PWM

- 频率 **20kHz**（高于人耳，避免啸叫），分辨率 10bit（0–1023）；
- 每路独立占空比，输出前**限幅 0–100%**；
- 上电/复位默认 **0**（电机不转），必须解锁后才允许输出。

### 5.6 安全逻辑（软件）

| 保护 | 触发 | 动作 |
|------|------|------|
| 失联 | >500ms 无有效指令 | 油门归零、姿态回平 |
| 倾角 | \|roll\| 或 \|pitch\| >60° | 立即停机（disarm） |
| 低压 | 电池 <3.5V（带载） | App 报警 |
| 严重低压 | 电池 <3.3V | 强制降落（缓降） |
| 解锁 | 上电默认锁定 | 必须显式解锁才输出 |
| 物理急停 | 拔电池 | 唯一 100% 可靠手段 |

## 6. FreeRTOS 任务规划（双核）

| 任务 | 核 | 频率 | 职责 |
|------|----|------|------|
| `vControlTask` | **Core1** | **400Hz** | 读 IMU → LPF → Mahony → 内环 PID → 混控 → PWM |
| （外环，在控制任务内分频） | Core1 | **100Hz** | 每 4 拍执行一次角度环 |
| `vCommTask` | **Core0** | **50Hz** | WebSocket 收指令 / 发遥测 |
| `vSafetyTask` | Core0 | 20Hz | 失联 / 倾角 / 低压 / 看门狗 |
| `vLedTask` | Core0 | 2Hz | 状态灯 |

**频率选择理由**：
- 内环 400Hz：MPU6050 在 400kHz I²C 读一帧约 0.35ms，余量足；
- 外环 100Hz：角度环不需要更快，标准做法；
- WiFi 50Hz：手动操控足够；再高会放大 WiFi 抖动；
- 不建议 500Hz+：收益小、抖动大。

## 7. 调试、测试与调参

- **桌面侧单元测试**：`test/` 用 native 环境跑 LPF / Mahony / PID / 混控 / 安全逻辑，
  喂合成数据断言输出，**不烧板就能验证算法**。
- **遥测**：`vCommTask` 把姿态、PID 输出、电压打包经 WebSocket 发到 App。
- **调参顺序**：先内环（角速度）→ 再外环（角度）→ 最后 yaw；
  先 roll/pitch → 后 yaw；先小增益 → 逐步加大到临界振荡再回退 30–50%。
- **安全调参**：先无桨 → 单轴测试架 → 系绳 → 低空。

### 9.1 硬件选型与 BOM

> 详细清单见 **`docs/BOM.md`**（必购 ≈¥74，板免费 ≈¥66）。

### 9.2 引脚分配（ESP32-S3 SuperMini，最终以原理图为准）

| 信号 | GPIO | 外设 | 说明 |
|------|------|------|------|
| I²C | GPIO8 / GPIO9 | SDA / SCL | 400kHz，MPU6050 + QMC5883L |
| M1 | GPIO1 | LEDC CH0 | 右前，20kHz |
| M2 | GPIO2 | LEDC CH1 | 右后 |
| M3 | GPIO3 | LEDC CH2 | 左后 |
| M4 | GPIO4 | LEDC CH3 | 左前 |
| VBAT | GPIO5 | ADC1_CH4 | 100k/100k 分压 + 100nF |
| 解锁 | GPIO10 | GPIO 输入 | 拨动开关（可选） |
| 状态灯 | GPIO48 | WS2812 | 板载 |
| USB | GPIO19/20 | 原生 USB | **勿占用** |
| 调试 | GPIO43/44 | UART0 | USB 串口 |

**注意**：GPIO26–37 涉及 Flash/PSRAM，不要占用；不同厂家 SuperMini 丝印不同，以实物为准。

> **电机安装（重要）**：8520 本体约 φ8.5mm，机架需 **φ8.6 压入孔 + 出线槽**；
> 现有 v8 板框的 φ14.2 电机位是按更大外径画的，**打样前必须改**（WORKPLAN P1-2）。

### 9.3 电源树

```
1S 3.7V ─┬─ 4× 8520 电机（经 AO3400 低边开关）
         ├─ MT3608 ──▶ 5V ──▶ ESP32 5V ──▶ 板载 LDO ──▶ 3.3V（MPU/mag）
         └─ 100k/100k 分压 ──▶ GPIO5（VBAT 采样，100nF 滤波）
```

- 5V 端并 **470µF + 10µF**（WiFi 峰值电流可达 400–500mA）；
- 3.3V 端并 **10µF + 0.1µF**；
- 电池插头选 PH2.0，**可快速拔断**（物理急停）。

### 9.4 首飞检查清单

- [ ] 拆桨上电，App 看姿态是否平稳（不抖、不发散）。
- [ ] 电机转向正确（Quad-X 对角同向、相邻反向）。
- [ ] 解锁逻辑就位，未解锁电机不转。
- [ ] 失联 500ms 自动收油（拔 WiFi / 关 App 实测）。
- [ ] 倾角 >60° 停机（手动倾斜实测）。
- [ ] 系绳或手托低油门，确认姿态回正。
- [ ] 电池电压显示正常、低压报警有效。

### 9.5 本期范围边界（阶段1）

> 阶段1 = **姿态自稳 + 航向锁定 + 手动飞行 + 短时小范围悬停（允许漂移）**。
> **不做**定高、定点、定距移动、自主航线（需光流/测距 + 位置环，见 §8）。

## 10. 决策记录 + 设计问题表

| # | 问题 | 结论 |
|---|------|------|
| Q1 | ESP32 性能够吗？ | 双核 240MHz，400Hz 控制 + WiFi 足够；**不建议单核 C3**（WiFi 与控制抢核，抖动大）。 |
| Q2 | 为什么用有刷？ | 便宜、驱动简单、1S 安全；代价是寿命短、效率低、抗风差。 |
| Q3 | 有刷 PWM 用多少？ | **20kHz / 10bit**（LEDC）。**不是**舵机 50Hz；低频会啸叫、抖动。 |
| Q4 | 1S 怎么给 ESP32 供电？ | 必须 **MT3608 升 5V**；AMS1117 从 3.7V 降压压差不够。 |
| Q5 | 磁力计能定点吗？ | **不能**。它只锁航向；水平位置仍会漂，定点需要光流/GPS。 |
| Q6 | 控制频率多少合适？ | **400 / 100 / 50Hz**（内环/外环/WiFi）。500Hz+ 收益小。 |
| Q7 | 安全怎么做？ | 失联 500ms、倾角 >60°、低压、解锁、物理急停，五道。 |
| Q8 | 8520 怎么固定？ | PCB 做 **φ8.6 压入孔 + 出线槽**；现有 v8 的 φ14.2 要改。 |
| Q9 | WiFi 延迟够吗？ | 10–20m、50Hz 指令，手动飞行够用；延迟明显时降低码率/关闭其他 2.4G。 |
| Q10 | 能定距移动吗？ | **不能**。需光流 + 测距 + 位置环，属后续扩展。 |
