## 4. 关键说明

- **供电必须升压**：1S 3.7V 直接进 AMS1117-3.3 压差不够（需 ≥4.4V），要 **MT3608 升到 5V** 再进 ESP32 的 5V/板载 LDO。
- **PWM 是 20kHz**（LEDC），**不是舵机 50Hz**；有刷电机用高频 PWM 才不啸叫、不抖。
- **引脚以实物为准**：N16R8 开发板不同厂家排布不同；**PSRAM 占用 GPIO35–37**，不要使用。
- **磁力计地址**：QMC5883P 是 **0x2C**（不是 QMC5883L 的 0x0D）。**L 版库不能用**，必须按 P 版寄存器映射；收货先扫 I²C 地址确认 = 0x2C。
- **电机安装**：8520 本体约 φ8.5mm，需 **φ8.6 压入孔 + 出线槽**；现有 v8 板框的 φ14.2 电机位是按更大外径画的，**要改**（见 WORKPLAN P1-2）。
- **尺寸**：N16R8 约 25.5×52.5mm，比 50×50 中心岛每边探出约 1.25mm，可接受；若想完全包住，把中心岛放大到 54×54。
- **安全必做**：失联 500ms 收油、倾角 >60° 停机、低电报警、解锁逻辑、物理急停（拔电）。
- 空心杯**寿命有限**（几十小时），飞行后摸电机是否发烫，发烫即降油门或换电机。

## 5. 引脚速查（ESP32-S3-N16R8，**以实物丝印为准**）

| 信号 | GPIO | 外设 |
|------|------|------|
| I²C SDA | GPIO8 | MPU6050 + QMC5883P |
| I²C SCL | GPIO9 | 同上 |
| M1 右前 | GPIO1 | LEDC CH0（20kHz） |
| M2 右后 | GPIO2 | LEDC CH1 |
| M3 左后 | GPIO3 | LEDC CH2 |
| M4 左前 | GPIO4 | LEDC CH3 |
| VBAT | GPIO5 | ADC1_CH4（100k/100k 分压） |
| 解锁开关 | GPIO10 | 拨动开关（可选，App 也可解锁） |
| 状态灯 | GPIO48 | 板载 RGB（若未引出则用外接 LED） |
| USB | GPIO19/20 | 原生 USB，**勿占用** |
| 串口调试 | GPIO43/44 | USB 串口（UART0） |
| **禁用** | GPIO35–37 | **PSRAM 占用** |
